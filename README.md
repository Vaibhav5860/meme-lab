Meme Lab is a playful, modular meme playground built with vanilla web tech. It blends meme browsing, creation energy, and interactive extras into one fast front-end experience.

![Meme Lab Hero](assets/screenshot/Screenshot%202026-03-29%20022842.png)

## Brand Vibe

- Loud, fun, and intentionally unserious
- Quick interactions, low friction, high replay value
- Built for both desktop and mobile meme sessions

## What You Can Do

- Explore memes by category
- Save favorites and track history
- Use keyboard shortcuts for speed
- Enjoy quiz, jokes API, slideshow, and sound modules
- Tune behavior with settings and privacy controls

## Tech Stack

- HTML5
- CSS3

## Quick Start

1. Clone or download the project.
2. Open `index.html` in your browser.
3. Start cooking memes.
